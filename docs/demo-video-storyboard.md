```text

  src/Composition.tsx
```

## 口播稿

大家好，我们是南京大学“我的刀盾队”，成员是曹喆和王佳铭。我们的项目是 TikTok Shop VideoPilot，对应课题是电商场景 AIGC 带货视频生成系统。

先看结果。这是一条 10 秒的竖版带货视频样例，画面由 Seedance 生成，字幕和 CTA 由系统后期渲染控制。我们的重点不是只做一个文生视频入口，而是把商家的真实工作流连起来：素材入库、剧本生成、分镜编辑、一键成片、任务追踪和数据回流。

在素材模块，商家可以上传商品图片、商品视频和参考素材，并填写来源声明。系统会把素材结构化为商品标签、视频摘要、slice 级标签和召回信息，后续剧本和创作模块可以按关键词、标签和相似度检索素材。

在剧本模块，系统会根据商品标题、卖点、目标人群、使用场景，以及创作策略和约束规则生成多套短视频剧本。用户可以继续修改 Prompt、分镜、字幕、镜头运动和素材 query，也可以对单个分镜局部重生成。

在创作模块，用户确认分镜后可以一键成片。后端会创建长任务，按分镜召回素材，优先调用 Ark / Seedance 生成视频片段，再由 FFmpeg 统一完成字幕、CTA、封面、画幅和导出。最终导出支持 9:16 和 16:9，并保证视频时长不超过 15 秒。

因为视频生成是长耗时任务，我们把每一步都记录在任务 trace 中，包括排队、模型调用、素材召回、音频处理、渲染导出和失败兜底。这样评委和开发者都能复核生成链路，而不是只看到一个黑盒结果。

除了生成视频，系统还提供 A/B 变体和数据看板。我们把 Hook、视觉风格、CTA、字幕密度、旁白语气等创作因子与 CTR、CVR、GMV、ROI 等指标关联起来，模拟内容投放后的数据回流，让 AIGC 视频生成服务于真实电商增长。

工程上，项目采用 React、Node.js 和 TypeScript 的前后端分离架构。前端是商家工作台，后端使用 Fastify 和 Prisma，长任务使用 Redis 与 BullMQ，视频合成使用 FFmpeg，AI 能力通过 Ark、Hybrid 和 Mock Provider 抽象。真实 API Key 和模型 Endpoint 只通过环境变量或部署 Secret 配置，不进入仓库或提交材料。

当前项目已经覆盖 P0 必做能力，并实现了多项 P1 和 P2 加分项，包括素材检索、分镜级编辑、生成 trace、失败重试、Mock 数据看板、A/B 对比、合规审核和真实 Seedance 生成样例。我们的目标是让商家能更快产出可控、可追踪、可优化的带货短视频素材。
